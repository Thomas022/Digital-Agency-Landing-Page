# Digital Agency Landing Page

A single-page, responsive landing page for **EsseDe Digital**, a fictional digital agency that specializes in process automation, business digitalization, and AI implementation. Built with plain HTML, CSS, and vanilla JavaScript — no frameworks, no build tools, no dependencies.

## ✨ Features

- **Hero section** with headline, CTAs, and key result metrics
- **Services overview** — three core service pillars presented as cards
- **About / Why Us** section with company stats
- **Case studies** highlighting client results
- **Testimonials** from (sample) clients
- **Pricing / plans** section with three tiers
- **Contact / lead form** with client-side validation and a simulated submit flow
- **Responsive navigation** with a mobile menu toggle
- **Smooth scrolling** for in-page anchor links and CTA buttons
- Auto-updating footer copyright year

## 🛠️ Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom styling, gradients, and responsive layout (`style.css`)
- **Vanilla JavaScript** — no libraries or frameworks (`script.js`)
- **Google Fonts** — Space Grotesk & Manrope

## 📁 Project Structure

```
Digital-Agency-Landing-Page/
├── index.html      # Main page markup
├── style.css        # All styling
└── script.js        # Navigation, smooth scroll, and form behavior
```

## 🚀 Getting Started

No build step or dependencies are required.

1. Clone the repository:
   ```bash
   git clone https://github.com/Thomas022/Digital-Agency-Landing-Page.git
   ```
2. Open the project folder:
   ```bash
   cd Digital-Agency-Landing-Page
   ```
3. Open `index.html` directly in your browser, or serve it locally, e.g.:
   ```bash
   npx serve .
   ```
   or with Python:
   ```bash
   python3 -m http.server
   ```
4. Visit `http://localhost:<port>` in your browser.

## 📬 Contact Form

The contact form on this page is a **front-end demo only**. On submit, it simulates a loading state and shows a confirmation alert — no data is actually sent anywhere. To make it functional, connect it to a backend endpoint or a form service (e.g., Formspree, Netlify Forms, EmailJS).
